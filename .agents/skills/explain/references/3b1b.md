# 3Blue1Brown Animations Reference (Manim)

Use this reference to generate 3Blue1Brown-style mathematical and algorithmic vector animations using Manim Community Edition.

---

## What Good Looks Like

- **Canvas & Palette**: Use a dark charcoal background (`#0e0e0e`), serif typography (`Times New Roman` or LaTeX math), and 3Blue1Brown signature accent colors (`BLUE`, `YELLOW`, `TEAL`, `GREEN`, `RED`).
- **Coordinate Boundaries**: Keep all geometry and text strictly within the 16:9 canvas ($X \in [-7, 7]$, $Y \in [-4, 4]$) using `.next_to()` buffers to prevent overlapping.
- **Dynamic Transforms**: Prefer smooth vector morphs (`ReplacementTransform`, `LaggedStart`, `Create`) rather than abrupt cuts.
- **Audio-Visual Harmony**: Synchronize scene pacing directly with Gemini TTS narration tracks using the `Orus` voice.

---

## Rendering Pipeline

Run Manim on demand with `uv`:

```bash
uv run --with manim manim -qm scene.py MyScene -o /tmp/animation_raw.mp4
```

Flags:
- `-ql`: 480p 15fps (fastest scratch preview)
- `-qm`: 720p 30fps (standard web embed)
- `-qh`: 1080p 60fps (high fidelity)

## Python Scene Template

```python
from manim import *
import numpy as np

class ConceptScene(Scene):
    def construct(self):
        # 1. Canvas Styling
        self.camera.background_color = "#0e0e0e"

        # 2. Header
        title = Text("Concept Title", font="Times New Roman", font_size=38, color=WHITE)
        title.to_edge(UP, buff=0.35)
        self.play(Write(title), run_time=1.0)

        # 3. Vector Geometry / Objects
        box = RoundedRectangle(corner_radius=0.15, height=2.5, width=4.0, color="#5dade2", stroke_width=2.5)
        box.shift(LEFT * 2.0 + DOWN * 0.5)
        
        target = Circle(radius=0.3, color=YELLOW, fill_color=YELLOW, fill_opacity=0.9)
        target.shift(RIGHT * 2.5 + DOWN * 0.5)

        arrow = Arrow(box.get_right(), target.get_left(), color=WHITE, stroke_width=2.5)

        self.play(Create(box), GrowArrow(arrow), Create(target), run_time=1.5)
        self.wait(1.0)
```

## Combining with Gemini TTS Narration

After generating the narration audio with `Orus` (see [`references/audio.md`](./audio.md)), mux the audio and video using FFmpeg without cutting off:

```bash
ffmpeg -y -i /tmp/animation_raw.mp4 -i /tmp/narration.mp3 -c:v copy -c:a aac /tmp/final_explainer.mp4
```
