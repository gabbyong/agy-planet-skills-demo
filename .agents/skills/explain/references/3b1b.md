# 3Blue1Brown Animations Reference (Manim)

Use this reference to generate 3Blue1Brown-style mathematical and algorithmic vector animations using Manim Community Edition.

## What Good Looks Like

### 1. Engaging 3Blue1Brown Storytelling & Visual Intuition
- **The Intuitive Hook**: Start directly with the visual friction point or mystery (e.g., "Why does noise break our model?", "Watch how the filter isolates the signal"). Draw the viewer in before introducing mathematical formalisms.
- **Dynamic Geometric Motion**: Avoid static text dumps or abrupt cuts. Use continuous vector flows, morphing geometries (`ReplacementTransform`, `LaggedStart`, `GrowArrow`, `Indicate`), and glowing focal pulses to make abstract transformations feel physical and alive.
- **Canvas & Palette**: Use a dark charcoal background (`#0e0e0e`), crisp modern typography, and standard Manim Community color tokens (`BLUE`, `TEAL`, `GREEN`, `YELLOW`, `RED`, `GRAY_A` through `GRAY_D`, or direct hex literals like `"#1a3838"`). Do not use invented tokens like `GREEN_ACCENT`.

### 2. Audio-First Pacing & Synchronized Keyframes
- **Always Generate Audio First**: Produce the spoken narration and measure its exact duration in seconds using `ffprobe` before writing the animation timeline.
- **Keyframe Allocation**: Budget animation run times so $\sum \text{run\_time} + \text{wait} = \text{duration}_{\text{audio}}$, aligning visual milestones directly with the speaker's vocal cues.
- **3D Loss Landscapes**: Use `ThreeDScene`, `ThreeDAxes`, and `Surface` with `self.begin_ambient_camera_rotation(rate=0.12)` to visualize optimization surfaces. Always lock HUD text using `self.add_fixed_in_frame_mobjects(title, legend)`.

## Rendering Pipeline

Run Manim on demand with `uv`:

```bash
uv run --with manim manim -qm scene.py MyScene -o /tmp/animation_raw.mp4
```

Flags:
- `-ql`: 480p 15fps (fastest scratch preview)
- `-qm`: 720p 30fps (standard web embed)
- `-qh`: 1080p 60fps (high fidelity)

## Combining with Voiceover Narration

After generating the narration audio, mux the audio and video using FFmpeg:

```bash
ffmpeg -y -i /tmp/animation_raw.mp4 -i /tmp/narration.wav -c:v copy -c:a aac -b:a 192k /tmp/final_explainer.mp4
```
